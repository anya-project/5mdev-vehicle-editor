## ⚡ Why Vehicle Editor?

Developing and managing vehicle resources in FiveM can be a messy and time-consuming process. Editing XMLs by hand, merging multiple resources into one pack, extracting nested RPFs, or debugging broken audio streams often requires juggling multiple outdated tools.

**5mdev Vehicle Editor** is an all-in-one, blazing-fast desktop application designed specifically to eliminate these headaches. Built with a modern interface and professional workflow in mind, it provides everything a FiveM developer needs in a single workspace.

## ✨ Key Features

- 🛠️ **Advanced Meta & Handling Editor:** Edit `vehicles.meta`, `handling.meta`, and `carcols.meta` with an intuitive graphical interface or use the Raw XML Code Mode.
- 📦 **Resource Merger & Splitter:** Combine multiple vehicle add-ons into a single optimized resource pack, or split a massive pack into individual standalone vehicles effortlessly.
- 🔊 **Built-in AWC Player & Sound Editor:** Listen to vehicle engine sounds directly inside the app! Swap audio hashes instantly without digging through complex data files.
- 🏎️ **3D Vehicle Preview:** Visualize vehicle models (.yft) directly in your workspace without having to open the game.
- 🗂️ **Nested RPF Extractor:** Deep scan and extract contents from nested `.rpf` files with a single click.
- 🔄 **Seamless In-App Auto Updater:** Stay up-to-date with silent background updates. Never visit a download page again after your first install.
